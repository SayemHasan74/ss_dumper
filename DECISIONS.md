# Decisions

- Use the selected E:\Codes\Drop folder as the repository root; keep Dump as the product and package name required by the spec.
- Keep ULIDs monotonic during clock rollback by retaining the last timestamp; advance the timestamp on random-field overflow to preserve uniqueness.
- Use 1 KB = 1024 bytes for gzip budgets so the limits are deterministic.
- Interpret the secret generator's Node crypto-only requirement as no third-party dependencies; use node:fs solely for the required .dev.vars output.
- Print credentials only in the explicitly requested interactive generator; verification captures output without displaying credentials.
- Include Vite client types for the CSS side-effect import under strict TypeScript checking.
- Require Node 22.12+ within the specified Node 20+ range because the selected current Wrangler, Vite, Vitest, and concurrently releases need it; verification uses the installed Node 24.20.0.
- Replace the R2-era Part 1 spec with the user's revised attachment verbatim; it is the current implementation source.
- Use the already-created dump-files KV namespace with binding FILES and the already-created dump-db D1 database; configure their verified IDs instead of creating duplicate resources.
- Keep storage behavior in Part 3; Part 1 only replaces the binding and documents the revised 900 MB cap and KV constraints.
- Do not add a global login lockout because an attacker could lock out the owner; counters use salted, hashed full IP addresses.
- Treat the bearer limiter as noise reduction only; a valid high-entropy upload token always passes without database access, even after invalid attempts.
- Use plain SHA-256 for the randomly generated 256-bit access/upload credentials; slow password hashing adds no useful protection and would consume the free Worker CPU budget.
- Use one D1 batch with INSERT, cleanup DELETE, and SELECT for recordFailure; the spec's requested SELECT is the third statement in the same atomic round trip.
- Apply the gate to OPTIONS and unknown methods like every other non-public API request; authenticated requests passing CSRF fall through to 404, while anonymous requests remain 401.
- Use Vitest's imported types and the existing dependency tree without installing @types/node; normalize TextEncoder output to an ArrayBuffer-backed Uint8Array and supply ignoreBOM to match installed Workers types.
- Use a discriminated type-prop spread for the password visibility toggle to satisfy Preact 11's installed input attribute types without casts to any.
- Preserve unselected local secrets when combining --only with --write-dev-vars, so rotation cannot silently invalidate unrelated credentials.
- Keep the login card minimal with system fonts, inline SVG, safe-area padding and light/dark contrast; discard the UI skill's unrelated marketing layout and external-font suggestions to follow the spec.
- Preview the production CSP on Wrangler's static asset server rather than Vite's development injection; no production CSP relaxation is allowed.
- Use JPEG thumbnails at quality 0.82 and longest side 480 px, with image/jpeg-only storage and serving, for the specified iOS-compatible client pipeline.
- Trust client SHA-256 solely for duplicate detection; KV cannot verify it, and the Worker never hashes or buffers original file bodies.
- Apply the approved Part 3 amendment: deleteMany returns failed and quotaExceeded, never throws, logs kv_delete_fail once without keys, and skips remaining delete groups after a quota failure.
- Return DAILY_LIMIT after D1 deletion for bulk purge and Empty Trash when quotaExceeded is true; permanent single-file deletion still succeeds and leaves failed KV deletion for orphan cleanup.
- Carry the approved amendment into Part 8: maintenance must stop purge/orphan KV steps on quotaExceeded and log maintenance_quota; do not implement maintenance in Part 3.
- Cancel the fixed-length readable stream as well as aborting the pipe after a rejected KV put, preventing backpressure deadlock; map the installed workerd FixedLengthStream TypeError to StorageLengthError for short bodies.
- Expose storageFor(env) inside storage.ts so no other Worker module directly accesses env.FILES; createStorage remains available for interface-focused tests.
- Split off the last path segment before stripping forbidden filename characters, then enforce the MIME extension within 200 code points; remove isolated UTF-16 surrogates so filenames remain safely percent-encodable.
- Use DELETE RETURNING in the atomic purge batch so only rows actually deleted produce KV deletes, avoiding removal of a concurrently restored file's objects.
- Use 8 KB JSON for upload hash checks, 4 KB for file metadata, 16 KB for bulk actions, and 1 KB for settings, preserving the specified route limits.
- Treat If-None-Match weak tags as matches for GET/HEAD as well as exact strong tags; conditional and HEAD responses never read KV.
- Preserve the required blank screen until the session check completes; following the user's instruction to choose the safest option, measure the cached-shell skeleton target from DOMContentLoaded and report full navigation separately (581.1 ms versus 1177.6 ms under Fast 3G). The latter does not meet a strict navigation-to-skeleton one-second target.
- Cap gallery content at 1440 px for readability while applying the specified column/cell formula to the measured padded content width.
- Replace the viewer history entry during next/previous navigation so Back closes the viewer in one step; keep the gallery mounted, lock body scroll, and remeasure after restoring it.
- Fetch viewer originals as blobs to inspect missing-object status before the one permitted propagation retry; revoke object URLs on file changes and close, and decode before fading/preloading.
- Keep thumbnail first-load/retry caches only for the signed-in gallery lifetime, preventing repeated automatic retries after virtualization remounts without persisting filters or file data.
- Verify browser behavior with installed Edge Chromium and its touch/network emulation without adding dependencies; real iPhone/Safari behavior remains a device check, not a claimed test result.
