- install: do nothing special (no precache list, because built asset names are hashed and unknown to this file). Do NOT call skipWaiting() automatically.
- activate: delete every cache whose name is not CACHE; clients.claim().
- message: { type: 'SKIP_WAITING' } -> self.skipWaiting().
- fetch rules, in order: ignore (let the network handle) any request that is not GET, not same-origin, whose path starts with /api/, or that has a Range header. Navigation requests (request.mode === 'navigate'): network-first with a 2.5 s timeout, on success store the response under key / (only if response.ok), on failure/timeout serve cached /. Requests under /assets/, /icons/, and /manifest.webmanifest: cache-first, fetch and store on miss (only response.ok, status 200). Everything else: network only. After each cache.put, trim the cache to 60 entries (delete oldest).
- Registration (pwa/register.ts): only when import.meta.env.PROD and 'serviceWorker' in navigator, after the window load event, register('/sw.js', { scope: '/' }). Check for updates (registration.update()) when the app returns to the foreground, at most once per 10 minutes.
